# fl-learn-to-unlearn

## Install LTU (Python 3.11.9):

``` python
cd fl-learn-to-unlearn
```

``` python
pip install -e .
```

### To run the script:

```python
python scripts/exp_fmnist.py
```

- Note: Data from FMNIST is used for this demo experiment as stored in ```./ltu/data/fmnist/```
